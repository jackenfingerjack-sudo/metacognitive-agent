# Performance Optimization

**When to use:** Making code or systems faster or more efficient.

## Steps
1. Define the performance goal and metric.
2. Measure a baseline under realistic load.
3. Profile to find the real bottleneck.
4. Apply targeted optimizations (algorithms, caching, I/O, batching).
5. Re-measure and compare against the baseline.
6. Document trade-offs and guard with benchmarks.
