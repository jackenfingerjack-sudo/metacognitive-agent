# Refactoring

**When to use:** Improving code structure without changing behavior.

## Steps
1. Ensure tests cover current behavior (add them if missing).
2. Identify code smells: duplication, long functions, tight coupling.
3. Plan small, safe refactoring steps.
4. Apply one change at a time, running tests after each.
5. Improve naming and module boundaries.
6. Review the final diff for unintended behavior changes.
