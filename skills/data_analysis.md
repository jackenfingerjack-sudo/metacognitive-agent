# Data Analysis

**When to use:** Analyzing datasets or interpreting statistics.

## Steps
1. Clarify the question the data should answer.
2. Inspect data: schema, size, missing values, outliers.
3. Clean and transform as needed, documenting each step.
4. Compute descriptive statistics and visualize distributions.
5. Test relationships or hypotheses with appropriate methods.
6. Report findings, limitations, and next steps.
