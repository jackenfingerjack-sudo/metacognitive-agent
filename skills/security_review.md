# Security Review

**When to use:** Assessing code or systems for vulnerabilities.

## Steps
1. Identify assets, entry points, and trust boundaries.
2. Build a quick threat model (e.g., STRIDE).
3. Check authentication, authorization, and session handling.
4. Look for injection, XSS, CSRF, and insecure deserialization (OWASP Top 10).
5. Review secrets handling, dependencies, and configuration.
6. Report findings by severity with remediation steps.
