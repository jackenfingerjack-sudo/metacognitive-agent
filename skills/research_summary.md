# Research Summary

**When to use:** Summarizing a topic, papers, or multiple sources into key findings.

## Steps
1. Clarify the question, scope, and intended audience.
2. Gather credible sources (use web_search for current info) and note publication dates.
3. Extract key claims, evidence, and data points from each source.
4. Group findings into themes and highlight agreements and contradictions.
5. Write a concise summary: TL;DR, key findings, open questions.
6. Cite sources and state confidence and gaps.
