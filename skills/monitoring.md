# Monitoring

**When to use:** Setting up observability, metrics, and alerts.

## Steps
1. Define what healthy means: SLIs and SLOs.
2. Instrument metrics, logs, and traces.
3. Build dashboards for key signals (latency, traffic, errors, saturation).
4. Create actionable alerts tied to SLOs.
5. Write runbooks for each alert.
6. Review alert noise and coverage regularly.
