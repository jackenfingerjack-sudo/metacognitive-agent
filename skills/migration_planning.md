# Migration Planning

**When to use:** Moving systems, data, or versions to a new platform.

## Steps
1. Inventory the current system, dependencies, and data.
2. Define the target state and success criteria.
3. Choose a strategy (big-bang, phased, strangler, dual-run).
4. Plan data migration, validation, and rollback.
5. Schedule cutover and communicate to stakeholders.
6. Monitor after cutover and decommission the old system.
