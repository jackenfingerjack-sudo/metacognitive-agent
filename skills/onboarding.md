# Onboarding

**When to use:** Helping a new team member ramp up.

## Steps
1. Set clear goals for the first week, month, and quarter.
2. Prepare access, tools, and environment setup steps.
3. Provide an overview of the product, architecture, and team.
4. Assign a buddy and a small starter task.
5. Schedule check-ins and feedback.
6. Collect feedback to improve the onboarding process.
