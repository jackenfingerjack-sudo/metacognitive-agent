# System Design

**When to use:** Designing scalable software architectures.

## Steps
1. Gather functional and non-functional requirements (scale, latency, availability).
2. Estimate load: users, QPS, storage.
3. Sketch high-level components and data flow.
4. Choose data stores and APIs with justification.
5. Address scaling, caching, fault tolerance, and consistency.
6. Discuss trade-offs and future evolution.
