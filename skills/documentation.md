# Documentation

**When to use:** Writing READMEs, guides, or API docs.

## Steps
1. Identify readers and their goals.
2. Outline: overview, quickstart, usage, reference, troubleshooting.
3. Write a minimal working quickstart first.
4. Add concrete examples for common tasks.
5. Keep language concise and consistent.
6. Add a maintenance note: versions and how to contribute.
