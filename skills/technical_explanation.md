# Technical Explanation

**When to use:** Explaining how a technology or concept works.

## Steps
1. Identify the audience's level and what they already know.
2. Start with a one-sentence plain-language definition.
3. Give an analogy or mental model.
4. Explain the mechanism step by step.
5. Show a small concrete example or code snippet.
6. Note common misconceptions and where to learn more.
