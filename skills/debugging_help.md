# Debugging Help

**When to use:** Diagnosing errors, crashes, or unexpected behavior.

## Steps
1. Collect the exact error message, stack trace, and environment.
2. Reproduce the problem with a minimal example.
3. Form hypotheses ranked by likelihood.
4. Test each hypothesis with targeted checks (logs, prints, debugger).
5. Apply the smallest fix that addresses the root cause.
6. Verify the fix and add a regression test.
